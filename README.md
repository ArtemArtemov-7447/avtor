## Описание
Это GUI-приложение на Python с использованием Tkinter для генерации случайных цитат. Приложение позволяет:
- Генерировать случайные цитаты из предопределённого списка (с текстом, автором и темой).
- Просматривать историю сгенерированных цитат в Listbox.
- Фильтровать историю по автору или теме.
- Добавлять новые цитаты с валидацией (проверка на пустые поля).
- Сохранять/загружать историю в JSON-файл.

Приложение использует модули `random`, `json`, `tkinter` и `messagebox`. Поддерживает русский язык. История сохраняется автоматически при закрытии/запуске.

## Требования
- Python 3.6+ (Tkinter включён по умолчанию).
- Нет внешних зависимостей.

## Примеры использования
### 1. Генерация цитаты
- Нажмите "Сгенерировать цитату".  
  Цитата отобразится вверху, добавится в историю снизу.

### 2. Фильтрация истории
- Введите в поле "Фильтр автора" (например, "Ганди") или "Тема" (например, "Мотивация").  
- Нажмите "Фильтр".  
- "Очистить" — показать все.

### 3. Добавление новой цитаты
- Заполните поля "Новая цитата", "Автор", "Тема".  
- Нажмите "Добавить".  
- Пустые поля вызовут ошибку.

### 4. Сохранение
- Нажмите "Сохранить историю" — данные в `history.json`.

## Возможные тесты
- **Тест 1:** Добавьте цитату с пустым автором → Ошибка.
- **Тест 2:** Сгенерируйте 5 цитат, отфильтруйте по теме → Показаны только matching.
- **Тест 3:** Закройте/откройте app → История сохранена.
- **Тест 4:** Git: `git add . && git commit -m "feat: add quotes" && git push`.
